Voice Notification API — Text-to-speech alerting

Context

Critical alerts sent by email or SMS were missed outside working hours. Operations needed a channel that actually interrupts.

My work

  • A REST API accepting a simple payload: a phone number and a message body.
  • The request is queued, converted to speech, and an automated voice call is placed.
  • Callable from any internal system — monitoring, ticketing or scheduled jobs.
